# NekoWatch App Edition

NekoWatch App is the desktop edition of NekoWatch, with native online playback powered by the NekoWatch API, anime discovery, library features, AniList integration, subtitles, SUB/DUB switching, and desktop playback support.

## Project identity

- Product name: **NekoWatch App**
- Edition: **App Edition**
- Website: **https://nekowatch.xyz**
- Repository: **meshahid973/nekowatch-app**
- Built-in streaming provider: **NekoWatch**

## Upstream

NekoWatch App Edition is an independent fork built on top of [Seanime](https://github.com/5rahim/seanime). Thanks to the original Seanime project and its maintainers for the foundation.

The upstream license and copyright notices are preserved. This repository remains licensed under the GNU GPL-3.0 license; see `LICENSE`.

## Development note

Some internal folders, Go import paths, sidecar binary names, and compatibility identifiers still use the historical `seanime` / `seanime-denshi` names. They are implementation details retained to avoid destabilizing the fork and are not the NekoWatch product identity.
